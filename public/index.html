How to get a GitHub Personal Access Token

Quick 30-second setup so GitStreak can push commits to your repo.

1
Open GitHub Token Settings

Go to github.com/settings/tokens/new (Personal Access Tokens - Classic).

2
Name Your Token & Set Expiration

Note: GitStreak Automation. Set expiration (e.g. 90 days or No expiration).

3
Select Scope: repo

Check the top checkbox labeled repo (Full control of private repositories). This allows the tool to create commits.

4
Generate and Copy Token

Scroll down, click "Generate token", and copy the string starting with ghp_.... Paste it into the GitStreak UI.

Database Configuration (MongoDB)

Persistent multi-user storage across restarts & cloud hosting.

Active Storage Engine: Checking...

GitStreak AI supports both MongoDB (Atlas or self-hosted) and Local Persistent Storage. When deployed to Render, setting your MongoDB URI guarantees your data and campaigns persist forever across restarts!

1
Get a Free MongoDB Atlas Database

1. Sign in to MongoDB Atlas (free tier available).

2. Create a Free Shared Cluster (M0).

3. Go to Network Access → Add IP Address: 0.0.0.0/0 (Allow Access from Anywhere).

2
Copy Connection String

Click Connect → Drivers → Copy the connection string:

mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/gitstreak?retryWrites=true&w=majority
3
Add Environment Variable

In your Render Dashboard (or local .env file), add:

MONGODB_URI=your_mongodb_connection_string

Save and deploy! GitStreak will automatically connect and persist all user accounts and streak campaigns.

Setup GitHub OAuth Login

Enable 1-Click "Sign in with GitHub" for yourself and your friends.

1
Create an OAuth App on GitHub

Go to GitHub Settings → Developer Settings → OAuth Apps and click "New OAuth App".

2
Fill in Application Details

• Application name: GitStreak AI

• Homepage URL: https://...

• Authorization callback URL:

https://.../api/auth/github/callback
3
Copy Client ID and Client Secret

Click "Generate a new client secret" and add these 2 environment variables to Render (or local .env):

GITHUB_CLIENT_ID=your_client_id
GITHUB_CLIENT_SECRET=your_client_secret
Open GitHub Developer Settings
